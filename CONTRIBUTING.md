# Contributing

For reproduction issues, include the repository commit, operating system, architecture, exact command and a minimal error excerpt. Do not post credentials, private operational logs or real customer data.

Corrections to documentation and reproducibility code are welcome. Frozen observations must not be overwritten, backfilled or silently replaced. Explain any correction and retain original hashes with a separate transformation record. New experiments belong in a separate, explicitly designed study.

Run `./verify.sh` before proposing changes that affect evidence or analysis. Changes to release contents require a reviewed checksum update; do not change scientific commitments to make a failing check pass.

The initial artifact is a research release, not a maintained production gate. Please avoid opening public issues containing sensitive security details.
